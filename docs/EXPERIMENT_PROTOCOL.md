# Experiment protocol

ASGC follows

`partial directed graph -> GAT preliminary edge completion -> target-specific in-strength calibration -> normalized aggregation weights -> aggregated signal`.

The eight calibration features are

`[tilde_c_i, o_i, p_i, n_i^o, n_i^m, mu_i^o, mu_i^m, sigma_i^m]`.

Ridge uses `lambda = 1`. The calibrated in-strength is projected to `[o_i, o_i+n_i^m]`. ASGC changes the in-strength used for aggregation and leaves the preliminary GAT edge estimates unchanged.

## Synthetic experiments

The public synthetic result release contains per-scenario records for Raw-GAT, GlobalMean, NodeMean, and ASGC, together with the seed manifests and bootstrap summaries used for the paper tables and figures.

Synthetic signal error uses the paper Eq. (3) channel-weighted L1 fused-signal metric with uniform `nu_p = 1/P`.

The development-set ablation reported in the paper compares BiasOnly, AggregateBasic, the full eight-feature ASGC model, and residual reassignment. Its reported values are stored in `results/frozen/synthetic/ablation_summary.csv`.

## METR-LA graph convention

The official adjacency is used directly after removing self-loops:

`A[j,i] = j -> i`

and target-node in-strength is

`c = A.T @ ones(N)`.

## METR-LA temporal split and node signals

- first 70%: training-side preprocessing information;
- next 10%: temporal evaluation windows;
- the reported evaluation reader accesses only this first 80% prefix.

For GAT completion, each sensor is represented by a standardized 12-dimensional descriptor formed from its training-period mean speeds over twelve two-hour bins. The downstream fusion signal is separate: each evaluation example uses a 12-step speed window ending at that evaluation timestamp.

## METR-LA relation masks

- the fixed 20-sensor subgraph contains 147 nonzero directed candidate relations; zero entries are outside the candidate relation set;
- development mask seeds: `2027101–2027105`, each used at both 40% and 70% observation;
- held-out evaluation mask seeds: `2027106–2027115`, each used at both 40% and 70% observation;
- observation ratios: 40% and 70%, sampled only within the 147-edge candidate support;
- GAT fit edges and validation edges are disjoint during training and early stopping;
- unobserved support edges belong to neither fit nor validation subsets;
- after checkpoint selection, the final completion pass may use all observed relations (fit plus validation) while predicting only unobserved candidate relations.

The final METR-LA StandardScaler/Ridge model is fitted only from scenarios generated by the five development mask seeds. The ten held-out mask seeds are used only for evaluation.

## METR-LA signal metric

For temporal evaluation window `t`, the real-data signal diagnostic is

`||sum_i (w_i-w_i_star) X_i^(t)||_2`.

The reported value is its mean across evaluation windows and is denoted by `E_{x,2}^{METR}`. This is separate from the weighted-L1 synthetic `E_x` used in the theoretical bound evaluation.
